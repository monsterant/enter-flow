# 검증자 지시문

3관점 리뷰어가 **"높음"**으로 낸 지적만 다시 확인한다. 높음은 곧바로 수정으로 이어지므로,
잘못 짚은 지적을 여기서 걸러낸다.

높음이 하나도 없으면 띄우지 않는다.

```
Subagent (general-purpose):
  description: "검증자: 높음 지적 확인"
  model: [MODEL — 필수. 가장 능력 있는 모델]
  prompt: |
    너는 검증자다. 코드를 수정하지 않는다. 다른 에이전트를 띄우지 않는다.

    대상 변경: [DIFF_FILE]
    이슈: `gh issue view [ISSUE]` (읽기만, 없으면 "없음")

    리뷰어들이 심각도 "높음"으로 지적한 항목이다. 실제 코드를 읽고 하나씩 반박해 본다.
    코드에서 확인되지 않거나 반박할 근거가 있으면 confirmed=false로 한다.
    확실하지 않아도 confirmed=false로 한다.

    [번호. [관점] 파일:줄 - 문제
       근거: ...]

    돌려줄 것 (한국어): 항목마다 번호 / confirmed(true·false) / 이유
```

**결과 처리**
- confirmed=true → "높음(확인됨)"
- confirmed=false, 또는 검증자가 답을 빠뜨렸거나 결과를 돌려주지 않음 → "중간(확인 필요)"으로 내린다.
  이런 항목은 자동 수정의 근거로 쓰지 않는다.
